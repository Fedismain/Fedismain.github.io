About me

Defensive security, built from the network up.

I'm Smain Fedi, a Cybersecurity Engineering student at EPI Digital School in Sousse, with a Bachelor's background in Computer Systems and Networks Engineering. My route into security started at the infrastructure layer — routing, switching, segmentation — and then moved toward the question that keeps me interested: how do you actually know an attack happened?

That question became my final-year project: a hybrid intrusion detection system that pairs signature-based rules with behavioural machine learning, deployed across a segmented virtual network. I generated the attack traffic, tuned the feature extraction, and compared what each detection method caught — including the cases where classic signatures stayed silent and behaviour-based detection did not.

I'm now specialising further at EPI, with a focus on defensive cybersecurity, security monitoring and incident investigation. I like work where the evidence matters: traffic captures, logs, confidence scores, and a clear answer about what happened and why.

Cybersecurity · Final Year Project

Hybrid Behavioural Intrusion Detection System

A hybrid IDS architecture combining pfSense, Snort signature rules and a Random Forest behavioural detection pipeline, running entirely in a VirtualBox environment.

  • Deployed a segmented virtual network with five VMs across WAN, DMZ, LAN and MGMT security zones.
  • Built a machine-learning IDS trained on 200,000 samples, extracting 71 traffic features with Scapy.
  • Generated and analysed attack traffic — Nmap scans, brute-force attempts, Slow HTTP and DoS scenarios — to evaluate detection.
  • Compared Snort signature detection with behavioural AI detection, showing improved identification of attack patterns including source IP changes.
  • Implemented a real-time traffic classification pipeline with confidence scores and security monitoring.
